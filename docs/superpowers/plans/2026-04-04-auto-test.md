# 自动测试体系实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立完整的自动化测试体系，包括快速测试、完整测试、Docker 测试和 Git Hooks

**Architecture:** 分层测试策略：快速测试 (gradlew test) → 完整测试 (test-all.sh) → Docker 测试 (docker-test.sh)

**Tech Stack:** Gradle, JaCoCo, Checkstyle, JUnit 5, Docker, Git Hooks

### Task 4: 创建 Docker 测试脚本

**Files:**
- Create: `scripts/docker-test.sh`

- [ ] **Step 1: 创建 Docker 测试脚本**

```bash
#!/bin/bash
set -e

cd "$(dirname "$0")/.."

echo "========================================"
echo "Running Docker Test"
echo "========================================"

# 1. 构建测试镜像
echo "[1/4] Building test image..."
docker build -t parking-netty-framework:test .

# 2. 启动测试容器
echo "[2/4] Starting test container..."
docker run -d \
    --name test-container \
    -p 8080:8080 \
    -p 8889:8889 \
    -e SERVER_PORT=8080 \
    -e NETTY_TCP_PORT=8889 \
    parking-netty-framework:test

# 等待容器启动
echo "Waiting for container to start..."
sleep 10

# 3. 健康检查
echo "[3/4] Running health checks..."
echo "  - Checking Java version..."
docker exec test-container java -version

echo "  - Checking HTTP health..."
curl -s http://localhost:8080/actuator/health || {
    echo "Health check failed!"
    docker stop test-container
    docker rm test-container
    exit 1
}

echo "  - Checking TCP port..."
nc -zv localhost 8889 || {
    echo "TCP port check failed!"
    docker stop test-container
    docker rm test-container
    exit 1
}

# 4. 清理
echo "[4/4] Cleaning up..."
docker stop test-container
docker rm test-container

echo ""
echo "========================================"
echo "Docker test passed!"
echo "========================================"
```

### Task 5: 创建 Git Hooks 安装脚本

**Files:**
- Create: `scripts/install-hooks.sh`
- Create: `scripts/hooks/pre-commit`

- [ ] **Step 1: 创建 pre-commit hook 模板**

```bash
#!/bin/bash

echo "Running pre-commit tests..."

# 快速测试
./gradlew test --quiet || {
    echo "❌ Tests failed! Commit aborted."
    exit 1
}

echo "✅ Pre-commit tests passed!"
exit 0
```

- [ ] **Step 2: 创建安装脚本**

```bash
#!/bin/bash

cd "$(dirname "$0")/.."

# 备份现有 hooks
if [ -f .git/hooks/pre-commit ]; then
    cp .git/hooks/pre-commit .git/hooks/pre-commit.backup
fi

# 安装 pre-commit hook
cp scripts/hooks/pre-commit .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit

echo "Git hooks installed successfully!"
echo ""
echo "Installed hooks:"
echo "  - pre-commit: Runs quick tests before commit"
echo ""
echo "To bypass pre-commit hook (not recommended):"
echo "  git commit --no-verify"
```

- [ ] **Step 3: 添加执行权限**
